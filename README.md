# Daily Clever Store

A responsive, polished storefront for thoughtfully selected everyday essentials. Built with plain HTML, CSS, and JavaScript so it can be hosted as a static site without a build step.

## Run locally

Open `index.html` in a browser, or serve this folder with any static web server. Product images and Google Fonts load from external providers.

## Included

- Responsive storefront with product categories and live search
- Product cards with add-to-bag interactions
- Slide-out cart with quantity controls, remove actions, and local storage persistence
- Newsletter signup confirmation and checkout demo interaction
- Accessible labels, keyboard escape-to-close behavior, and reduced-motion support

The checkout and newsletter are front-end demos; they do not process payments or subscribe addresses to a mailing list.
